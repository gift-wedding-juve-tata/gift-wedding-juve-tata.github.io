Info acara

Ditampilkan sebagai hitung mundur di halaman tamu. Kosongkan tanggal untuk menyembunyikannya.

  1. Buka GitHub → Fine-grained token (login sebagai gift-wedding-juve-tata).
  2. Repository access: Only select repositories → gift-wedding-juve-tata.github.io.
  3. Permissions → Repository → Contents: Read and write. Expiration: setelah acara selesai.
  4. Generate, salin token, tempel di bawah lalu Simpan.

Setelah disimpan, situs butuh ±1 menit untuk ter-update.
